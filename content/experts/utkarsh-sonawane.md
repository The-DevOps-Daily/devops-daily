## About Me

Most of my work lives in Python — research prototypes, automation scripts, and tooling — and I care a lot about reproducible workflows: version-controlled everything, CI that actually catches things, and environments you can rebuild from scratch. ## My Stack

The tools I reach for every day, and how they fit together:

- **GitHub Actions** for CI pipelines — tests and checks on every push, no separate CI server to babysit
- **Docker** for local development — every project gets a container so "works on my machine" stops being a joke
- **Kubernetes (learning)** for orchestration concepts — currently ramping up via labs and kind clusters
- **Terraform (learning)** for infrastructure as code — declarative infra beats click-ops tribal knowledge
- **Python + uv** for automation and research tooling — fast env setup, reproducible runs
- **Prometheus + Grafana (learning)** for metrics — because you can't fix what you can't see

I chose this combination because it's the shortest path from code to a reproducible, observable system: version-controlled everything, automated checks before merge, and containers that behave the same locally and in CI. The biggest win has been killing "it worked on my laptop" bugs — containerized dev environments plus CI parity mean environment surprises are rare instead of routine.
