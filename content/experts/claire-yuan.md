## About Me

I build software where civic technology meets law. My main project is BillBreaker, a mobile app that translates legislative text into plain English and shows young voters how a bill could affect them. It's built with Expo, Supabase for authentication, and a Cloudflare Workers API proxy that keeps API keys off the device.
I've also prototyped an AI-powered contract analysis tool and I write about technology and policy. I'm newer to DevOps, so I'm here to learn from this community, and I'm especially interested in deployment, serverless infrastructure, and security.
