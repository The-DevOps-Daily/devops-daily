## About Me

I'm from Nepal and based in Ahmedabad, India, where I'm a full-stack engineer at [Zuru Tech](https://zuru.tech). I work on frontend architecture and user experience. Most of my day-to-day work is in Next.js, TypeScript, Node.js, and Postgres, often inside Turborepo and pnpm monorepos. On my own projects I build backend services in Rust with axum and Postgres.

## Projects

- **[Notils](https://notils.com)**: An AI-native communication platform that helps applications generate, orchestrate, deliver, and observe customer communication across channels. Its services are written in Rust and start from a shared Rust service template
- **[RentDera](https://rentdera.com)**: A rent-management app for landlords in Nepal that generates monthly dues, records payments, issues PDF receipts, tracks utility meter readings, and sends reminders over WhatsApp or SMS. Built with a Rust API and a React Native mobile app, in English and Nepali with Bikram Sambat dates
- **[Juryza](https://github.com/sanjaysah101/Juryza)**: An open-source, self-hosted hackathon management platform covering team registration, project submissions, weighted scoring, z-score normalization, and pairwise ranking
- **[create-notils](https://www.npmjs.com/package/create-notils)**: A CLI that scaffolds a production-ready Next.js project (Turborepo, Bun, Tailwind v4, shadcn/ui on Base UI, and Biome) as a monorepo or a standalone app in one command
- **[RESTless](https://github.com/sanjaysah101/restless)**: A visual API mocking engine that lets frontend teams keep moving before the backend is ready
