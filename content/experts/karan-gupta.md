## About Me

I am a Systems Architect and Founder at Gupta Ventures, focusing on low-latency infrastructure, native desktop integrations, and autonomous DevOps tooling. As a contributor to major open-source ecosystems including Tauri and Kestra, I architect resilient, zero-downtime automated deployment sentinels and high-performance cross-platform applications.

### Core Focus Areas

- **Systems & Native Desktop Engineering**: Low-level Windows/Linux IPC, single-instance process coordination, and memory-safe Rust services.
- **Autonomous DevSecOps & Security**: Static analysis, AI-driven STRIDE threat modeling, and continuous vulnerability remediation pipelines.
- **Declarative Orchestration & SRE**: Disaster recovery automation, WAL journal checkpoints, and containerized cloud pipelines.

## My Stack

### Systems & Desktop
- **Rust** for native high-performance IPC, single-instance coordination, and memory-safe system services
- **Tauri v2** for ultra-lightweight desktop user interfaces with native OS hooks

### CI/CD & Automation
- **GitHub Actions** for multi-platform build matrices (Windows, Linux, macOS) and automated cryptographic release signing
- **Kestra** for declarative workflow orchestration, scheduled database backups, and health sentinels

### Cloud & Container Infrastructure
- **Docker** for reproducible build toolchains and isolated testbeds
- **AWS S3 / Cloudflare R2** for immutable snapshot storage and artifact archiving
- **SQLite (WAL Mode)** for low-overhead, embedded transactional persistence

### Security & Observability
- **ForgeGuard** for autonomous static analysis and STRIDE threat modeling
- **Slack Webhooks & OpenTelemetry** for real-time operational failure alerting

### Why This Stack
I architect systems around memory safety, zero-overhead runtimes, and deterministic state. Pairing Rust and Tauri eliminates heavy webview and Chromium runtime bloat, while Kestra and GitHub Actions ensure that every deployment and recovery step is fully declarative and auditable.
