### [OpenTofu 1.13 Re-Encodes base64gzip and Drops WinRM. We Upgraded the Same State to See What Breaks](https://devops-daily.com/posts/opentofu-1-13-upgrade-base64gzip-winrm)

### [A Poisoned .git/config Runs Code on git status. We Tested Which Commands and Copies Carry It](https://devops-daily.com/posts/poisoned-git-config-git-status-runs-code)

![A Poisoned .git/config Runs Code on git status. We Tested Which Commands and Copies Carry It](/images/posts/poisoned-git-config-git-status-runs-code.jpg)
